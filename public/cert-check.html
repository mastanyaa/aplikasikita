Memeriksa Sertifikat...

Memverifikasi sertifikat keamanan pada perangkat Anda sebelum dialihkan ke portal HTTPS.

Perangkat Anda belum memiliki sertifikat Root CA lokal. Unduh dan pasang sertifikat agar dapat mengakses aplikasi secara aman.
Unduh Sertifikat (.CRT)
Panduan Instalasi (Windows)
  1. Buka file aplikasikita.crt yang baru diunduh.
  2. Klik tombol Install Certificate...
  3. Pilih opsi Local Machine lalu klik Next.
  4. Pilih Place all certificates in the following store lalu klik Browse...
  5. Pilih folder Trusted Root Certification Authorities → klik OK → Next → Finish.
  6. Klik tombol Cek Ulang di atas atau muat ulang browser Anda.
